# Wasserstein-K-Center-Clustering-with-Robust-Validation

This repository contains the code and manuscript for Wasserstein K-center and K-median clustering with robust validation metrics.

## Overview

This project implements a complete clustering framework for distribution-valued data in Wasserstein space, including:

- Semi-free support Wasserstein barycenters
- Wasserstein Fréchet medians via IRLS
- Wasserstein K-median / K-center clustering
- ReD: a depth-based validation metric for selecting the number of clusters
- A Pollard-type consistency result for Wasserstein K-means

The full manuscript describing the framework, theory, and experiments is provided here:

- **Manuscript.pdf**

Two implementations are included:

- **Fixed-support version/** – fixed support 
- **Semi-Free Support Version/** – semi-free-support
